## 📖 About The Project

**Talkncode** is a comprehensive, real-time interview platform designed to streamline the technical hiring process. It seamlessly combines high-quality video calling with a synchronized, multi-language code editor, allowing invigilators and candidates to collaborate effectively. 

Whether you are conducting a collaborative pair-programming session or an automated coding challenge, Talkncode provides the exact tools needed to evaluate candidates fairly, efficiently, and in real-time.

## ✨ Key Features

* 💻 **Multi-Language Code Editor**: Run and compile code in various programming languages directly in the browser.
* 📹 **Real-time Video Calling**: High-definition, low-latency video and audio communication built right into the interview environment.
* 🛡️ **Invigilator Controls**: Verify coding challenges on the fly according to the interviewer's specific parameters.
* 🔴 **Interview Recordings**: Record sessions for later review and evaluation.
* ⚡ **Live Synchronization**: See the candidate's keystrokes in real-time, backed by an ultra-fast backend.
* 🎨 **Modern UI/UX**: A clean, accessible, and intuitive dashboard tailored for both interviewers and interviewees.

## 🚀 Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

* Node.js (v18 or higher)
* npm, yarn, pnpm, or bun
* A [Convex](https://convex.dev/) account for the backend database.

### 1. Installation

Clone the repository and install dependencies:

```bash
git clone [https://github.com/Wrostdevil/Talkncode.git](https://github.com/Wrostdevil/Talkncode.git)
cd Talkncode
npm install

**2. Environment Variables
Create a .env.local file in the root directory and add your required API keys.

Code snippet
# Convex Deployment
CONVEX_DEPLOYMENT=your_convex_deployment_url
NEXT_PUBLIC_CONVEX_URL=your_next_public_convex_url

# Add any other required keys here (e.g., Clerk Auth, Stream Video API keys, etc.)
3. Run the Development Server
Start the application:

Bash
npm run dev
Open http://localhost:3000 in your browser to see the application running.
